## Gates
- Knowledge coverage: PASS — five approved nodes represented.
- Assessment alignment: PASS — four assessment targets represented.
- Misconception diagnostics: PASS — core misconception classes have remediation paths.
- Scientific reasoning: PASS — observation is separated from inference; evidence is not overstated as proof.
- Age/safety: PASS — learner-facing transfer tasks do not require smelling or handling unknown substances.
- Assessment quality: PASS — unseen mastery contains constructed-response evidence and rubric requirements.
- Mastery rule: PASS — 19/20 is the numerical threshold, but unresolved critical misconceptions block mastery.
- Transfer: PASS — four novel-context transfer items function as a separate gate.

## 95% mastery protocol
A learner may receive `MASTERED` only when:
1. unseen mastery accuracy is >= 95%;
2. all core objectives are sampled;
3. no critical misconception remains unresolved;
4. transfer gate is passed;
5. constructed responses meet their rubric requirements.

## Important qualification
The 95% target is a lesson-level mastery target on a validated unseen set. It is not a statistical guarantee of achieving 95% on an external Wuhan examination. Wuhan examination materials remain an external calibration layer for competency and item demand.
