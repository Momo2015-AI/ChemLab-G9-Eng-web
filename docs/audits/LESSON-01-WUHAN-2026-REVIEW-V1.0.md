## 3. 对Lesson 01的明确要求

2026证据进一步支持本课必须训练：
1. 生活/实验情境中的变化识别；
2. “变化”和“性质”的语言辨析；
3. 不能把单一现象直接当作结论；
4. 用“是否生成新物质”作为物理变化/化学变化核心依据；
5. 陌生情境迁移；
6. 解释理由而非只选答案。
