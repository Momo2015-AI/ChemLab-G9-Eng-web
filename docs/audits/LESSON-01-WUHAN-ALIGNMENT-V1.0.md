## 真题使用规则

1. 真题作为校准样本，不直接复制到课程题库。
2. 每道真题必须记录年份、题号、原题考点、能力类型、正确答案和评分标准。
3. 真题中的语言和情境可以用于分析命题规律，但正式课程练习应重新命制，避免学生依赖记忆答案。
4. 只有完成逐题核验后，才能把某一道真题标记为“已映射”。
