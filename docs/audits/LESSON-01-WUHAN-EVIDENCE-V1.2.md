## 3. 对课程开发的实际结论

当前可以可靠使用武汉真题来校准：

- 变化与性质的概念辨析；
- 是否生成新物质的证据推理；
- 现象、证据、结论之间的关系；
- 物理性质与化学性质的分类；
- 陌生情境中的迁移判断。

但在获得可直接审阅的完整试卷文本和评分标准后，才能建立：

`年份 → 题号 → 原题考点 → 能力类型 → 答案 → 评分点 → Lesson Step → Mastery覆盖`

## 4. 防止错误对齐

禁止：

- 根据网上解析标题猜题号；
- 用湖北省真题冒充武汉市真题；
- 用模拟题冒充正式中考题；
- 没有评分标准就声称完成评分点映射；
- 为了满足“95%”而反向修改结论。
