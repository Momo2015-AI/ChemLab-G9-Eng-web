## 3. 内容标准

### 科学性
1. “物理变化”的定义：没有生成其他物质。
2. “化学变化”的定义：生成其他物质。
3. “物理性质”是不需要发生化学变化就能表现出来的性质。
4. “化学性质”是在化学变化中表现出来的性质。
5. 颜色变化、气泡、放热等是可能的现象证据，不可机械地作为“生成新物质”的充分条件。

### 教学性
每个概念必须经过：
现象/情境 → 讲解 → 例子 → 判断 → 即时反馈 → 迁移。

### 适龄性
避免大学化学术语、复杂微观模型和超出九年级要求的计算；使用生活情境和简单实验事实建立概念。
