# V1.9 Question Rebuild — Batch 01

## Scope

Rebuild the first quarantined placeholder families instead of preserving synthetic filler questions.

## Rebuild policy

- Preserve canonical question IDs only when downstream references require them.
- Replace placeholder wording with complete, grade-9-appropriate chemistry items.
- Every rebuilt item must have: stem, options/answer, explanation, knowledge links, difficulty, cognitive level, curriculum evidence, scientific review, age-suitability review, and item-quality review.
- No item enters `ready` with unresolved P0/P1 issues.
- Experimental questions must state relevant conditions and distinguish observation from conclusion.
- Chemical terminology must distinguish substances, solutions, ions, and mixtures accurately.

## Batch 01 priorities

1. Acids / bases / indicators
2. Salts and fertilizer
3. Ferrous / ferric chemistry
4. Common laboratory gases
5. Metals and extraction
6. Stoichiometry and equation reasoning

## Placeholder handling

The 60 known placeholder items remain quarantined. They are not counted as publication-ready content. Replacements are created against curriculum gaps rather than generated to preserve an arbitrary total of 320.

## Acceptance gate

A replacement is publishable only when all five evidence dimensions are present:

- curriculum
- scientific
- ageSuitability
- itemQuality
- knowledgeLinks

P0 issues block publication.
