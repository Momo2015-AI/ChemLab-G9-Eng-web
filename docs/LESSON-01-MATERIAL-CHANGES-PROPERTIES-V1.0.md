# Benchmark Lesson 01 — 物质的变化和性质

**Status:** GOLDEN-LESSON-V1 refinement
**Curriculum:** 人教版九年级化学上册·第一单元·课题1
**Authority:** 2022版义务教育化学课程标准 + 人教版教材；教师教学用书逐项校准；武汉中考真题仅作 S2 考试能力校准。

## 1. Lesson positioning

这是 ChemLab 的第一节 Golden Lesson。目标不是让学生背四个定义，而是建立整个初中化学通用的“证据 → 判断 → 解释”思维框架。

**核心问题：**

> 当我们看到一个现象时，怎样从“看到了什么”走向“发生了什么”，并判断有没有生成新物质？

## 2. Learning objectives

学生完成本课后能够：

1. 区分观察事实与解释/结论。
2. 用“是否生成新物质”判断物理变化和化学变化。
3. 区分“性质”和“变化”，并说明二者描述对象不同。
4. 判断物理性质与化学性质，并能用证据说明理由。
5. 面对陌生情境时，不依据单一现象武断下结论，而是主动寻找更充分证据。

## 3. Prerequisite

无学科前置要求。学生需要具备日常观察、比较和简单分类能力。

## 4. Lesson flow

## 5. Anchor phenomenon

采用学生熟悉、低风险的日常变化作为入口，例如冰融化、纸张形状改变、食物发生明显变化等。课堂材料必须由教师依据学校实验安全规范选择；学生不自行混合未知物质，也不自行进行危险实验。

核心观察表：

| 情境 | 我观察到的事实 | 我推断的变化 | 新物质证据 | 结论可信度 |
|---|---|---|---|---|
| A |  |  |  |  |
| B |  |  |  |  |
| C |  |  |  |  |

**教学要求：**先填“观察事实”，再填“解释”。教师不直接给出结论。

## 6. Concept model

### 6.1 物理变化

没有生成其他物质的变化。

判断时不能只看“外观变化大不大”，关键是变化前后是否还是同一种物质。

### 6.2 化学变化

生成其他物质的变化。

“是否生成新物质”是概念核心；颜色、气泡、沉淀、发光、放热等都属于可能观察到的现象，不能把其中任何一个现象机械地等同于“化学变化”。

### 6.3 物理性质

物质不需要发生化学变化就能表现出来的性质，例如颜色、状态，以及某些可以测量或观察的物理特征。

### 6.4 化学性质

物质在化学变化中表现出来的性质，例如可燃性、与某些物质发生化学反应的能力。

## 7. The four-concept matrix

| | 描述“过程” | 描述“物质特征/能力” |
|---|---|---|
| 不涉及新物质生成 | 物理变化 | 物理性质 |
| 涉及新物质生成/反应能力 | 化学变化 | 化学性质 |

关键句：

> **变化回答“发生了什么”；性质回答“这种物质有什么特征或反应能力”。**

## 8. Evidence ladder

学生使用三级证据框架：

**Level 1 — 现象：**我看到了什么？

**Level 2 — 证据：**这些现象能说明什么？还可能有其他解释吗？

**Level 3 — 结论：**现有证据是否足以支持“生成新物质”的判断？

这一步是本课最重要的能力训练之一。

## 9. Misconception diagnosis

### M1：有气泡 = 化学变化

**诊断：**学生把一个现象直接当成结论。

**补救：**追问“气泡中的物质是什么？仅凭气泡能确定它是新物质吗？”

### M2：颜色改变 = 化学变化

**诊断：**把明显现象当作定义标准。

**补救：**要求学生寻找“新物质”层面的证据。

### M3：性质 = 变化

**诊断：**把“可燃性”和“燃烧”混为一谈。

**补救：**使用句式：“___是物质表现出来的能力；___是实际发生的过程。”

### M4：物理变化一定容易恢复，化学变化一定不能恢复

**诊断：**把常见经验当作定义。

**补救：**明确“是否容易恢复”不是物理变化/化学变化的定义标准。

## 10. Guided practice

### Q1 — 性质还是变化？

A. 某物质是无色液体。
B. 某物质受热后生成另一种物质。
C. 某物质具有可燃性。

**答案：**A、C 是性质；B 是变化。

### Q2 — 证据够不够？

观察记录只有“产生气泡”。能否直接得出“发生了化学变化”？

**答案：**不能。气泡只是现象，仍需判断是否生成了新物质。

### Q3 — 概念边界

“可燃性”和“燃烧”分别是什么？

**答案：**可燃性是化学性质；燃烧是化学变化。

### Q4 — 反例意识

某变化看起来很明显，但如果没有生成新物质，能否因此称为化学变化？

**答案：**不能。现象明显不是定义标准。

## 11. Transfer task

给出一个学生熟悉的日常情境，让学生完成：

1. 写出两个可观察事实；
2. 区分事实与推断；
3. 判断这是“变化”还是“性质”描述；
4. 如果是变化，说明判断新物质所需的证据；
5. 给出结论，并说明结论依据。

评分重点不在术语数量，而在“证据—结论”是否对应。

## 12. Exit Ticket

1. 物理变化与化学变化最核心的区别是什么？
2. 物理性质与化学性质分别描述什么？
3. 为什么“产生气泡”不能单独作为化学变化的充分依据？
4. “可燃性”和“燃烧”为什么不能归为同一类？

**掌握标准：**4题中至少3题概念正确，且第3题必须明确提到“新物质/充分证据”。未达到标准进入补救任务。
