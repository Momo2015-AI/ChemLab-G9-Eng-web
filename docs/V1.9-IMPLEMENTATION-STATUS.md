# ChemLab-G9 V1.9 Implementation Status

## Scope

V1.9 turns the frozen V1.8 learning engine into a student-facing learning loop without introducing a second runtime, state store, content source, mastery engine, diagnosis engine, or recommendation engine.

## Implemented in this batch

- Learning Center home surface with course progress and primary actions.
- Interactive lesson surface with learning sections, knowledge-point identifiers, completion and assessment/experiment entry actions.
- Assessment route wired to the canonical `AssessmentController` and existing diagnosis/remediation flow.
- Remediation route wired to targeted recheck and transfer actions.
- Dashboard upgraded to show completion, mastery, question evidence, diagnosis and remediation status.
- Experiment route upgraded to observation/evidence feedback and completion.
- Production composition root now selects the V1.9 lesson and experiment view adapters.

## Architecture rule

All V1.9 UI actions delegate into the existing V1.8 controllers/services. No view owns domain policy.

```text
index.html
  -> app/bootstrap.js
  -> app/application.js
  -> controllers
  -> services
  -> canonical engines
  -> V1.9 views
```
