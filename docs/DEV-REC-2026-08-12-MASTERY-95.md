# Development Log — 2026-08-12 — 95% Mastery Requirement

## User decision
The target for a completed ChemLab lesson is approximately **95% accuracy on representative unseen assessment items** aligned to the lesson's approved learning objectives.

## Engineering consequence
The lesson is not considered mastered merely because the learner completes the page or answers the training examples correctly. The learning loop must include diagnostic assessment, targeted remediation, recheck with new items, and transfer verification.

## Assessment rule
The 95% threshold applies to a validated lesson-level assessment set. It is a mastery target, not a guarantee of an external examination score.

## Wuhan exam calibration
Wuhan middle-school chemistry examination materials remain an S2 external calibration layer. They are used to calibrate coverage, reasoning demand, transfer and examination style, but cannot expand the approved curriculum boundary.

## Next action
Re-audit Lesson 01's assessment blueprint and practice set against the 95% mastery standard, then revise the lesson until the full mastery loop can be demonstrated.
