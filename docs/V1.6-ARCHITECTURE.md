# ChemLab-G9-S2-web V1.6 Architecture

## Version Position

V1.5 has completed the learning platform foundation:

- Single page learning interface
- Daily learning path
- Knowledge modules
- Question engine
- Progress and growth UI

V1.6 continues from the existing architecture. It does not rebuild the project.

## V1.6 Goals

1. Separate teaching content from UI code
2. Build Chemistry LAB Engine foundation
3. Create experiment data model
4. Prepare instrument icon library
5. Prepare future AI diagnosis engine

## LAB Engine Model

Each experiment should support:

```json
{
  "title": "实验名称",
  "goal": "实验目的",
  "equipment": [],
  "materials": [],
  "steps": [],
  "phenomenon": [],
  "equation": [],
  "safety": [],
  "report": []
}
```
