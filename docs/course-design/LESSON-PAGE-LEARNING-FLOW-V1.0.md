# 第一课页面学习流程规范 V1.0

日期：2026-08-13
适用：ChemLab-G9-Eng-web 全部课程页
首个验收样本：Lesson 01《物质的变化和性质》

## 一、设计视角

页面不是“内容目录”，而是一个初三学生完成一节课的学习路径。
学生进入页面后应该始终知道三件事：

1. 我现在学什么？
2. 我下一步做什么？
3. 我怎样知道自己真的学会了？

## 二、学生实际学习顺序

### 0. 进入课程
- 看到课程名称、学习目标、预计时间和整体流程。
- 不首先看到大量题目或技术术语。

### 1. 先学懂
- “本节课要掌握什么”作为短目标区，而不是正文。
- “一步一步学”是页面主体。
- 每一步包含：核心讲解 → 例子/证据 → 即时检查 → 反馈。
- 默认展开当前推荐步骤，其余步骤可回看。

### 2. 再动手/观察
- 学完核心概念后进入实验探究。
- 实验结构：任务 → 观察 → 记录 → 证据 → 结论。
- 实验不是独立游戏，而是验证刚学知识。

### 3. 再练习
- 基础练习紧跟实验之后。
- 目的不是追求高分，而是检查是否真正理解。

### 4. 出错就诊断
- 错误必须关联到知识点和错误类型。
- 学生看到“哪里错了”和“为什么错”，而不是只看到错题数量。

### 5. 补救与再检测
- 根据薄弱知识点返回对应讲解。
- 完成少量针对性题目后再次检查。
- 已掌握知识不重复刷题。

### 6. 最终 Mastery
- 使用未直接见过的变式/陌生情境。
- Lesson 01：20题，≥19题正确即达到95%。
- Mastery 是“是否掌握”的证据，不是普通练习。

### 7. 完成本课
- 只有 Mastery 达标后解锁。
- 完成后返回学习中心，下一课成为推荐学习目标。

## 三、页面视觉优先级

1. 当前学习阶段
2. 当前要做的事情
3. 核心知识内容
4. 即时反馈
5. 下一步
6. 可选回看内容

不要让“知识点数量、题目数量、技术状态”等开发信息压过学生真正要学习的内容。

## 四、允许回看，但不允许伪造掌握

课程不采用僵硬的“上一阶段完成后才能点击下一阶段”锁链。学生可以回看知识、实验和练习；但是：

- 不能通过点击按钮直接标记完成。
- Mastery 成绩必须由 Assessment Runtime 计算。
- 未达到95%时进入补救，而不是显示“已掌握”。

## 五、第一课验收标准

- [x] 学习目标与课程标题一致
- [x] Guided Learning 全部可呈现
- [x] 实验资源可进入
- [x] 基础练习可进入
- [x] 诊断/补救有明确位置
- [x] Mastery 独立于基础练习
- [x] Mastery 阈值为95%
- [x] 完成本课有 Mastery 门禁
- [x] 数字答案与 A/B/C/D 答案索引统一
- [ ] 浏览器实际端到端回归测试

## 六、禁止的页面模式

- 只显示“本节课要掌握什么”，下面没有正文。
- 把所有内容压成知识卡片，没有深入讲解。
- 练习、实验、Mastery 随意排列，没有学习目的。
- 点击“完成”即获得课程完成状态。
- 正确答案因为不同数据格式被全部判错。
