# V1.7 Phase 1.11 — Remove Legacy Rendering from engine/app.js

## Completed

`engine/app.js` has been replaced with a minimal stub that exports nothing and documents that all rendering has migrated to the new `app/` and `views/` modules.

The original 917-line monolith has been archived at `engine/app.js.bak`.

## What was removed

- All `render*()` methods (home, course, quiz, result, graph, dashboard, experiment)
- The `ChemLabApp` class and global `window.app` initialization
- Direct DOM manipulation and inline event binding

## What remains in engine/

The domain engines are unchanged and still functional:
- `engine/content-loader.js` — data loading (used by `app/content-service.js`)
- `engine/assessment-engine.js` — quiz evaluation
- `engine/experiment-engine.js` — experiment step management
- `engine/knowledge-engine.js` — knowledge graph operations
- `engine/diagnosis.js` — mistake diagnosis

These engines are imported by the new controllers and remain the source of domain logic.

## Entry point

`index.html` now loads `app/bootstrap.js` which wires the new composition root. No legacy rendering code runs on page load.
