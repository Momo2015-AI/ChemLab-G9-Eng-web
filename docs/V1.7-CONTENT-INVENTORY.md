# V1.7 Content Inventory — Phase 3.1

## Verified source boundary

The current runtime still reads lesson/question/knowledge-graph data from `modules/`, while experiments and knowledge detail records are read from `content/`. Therefore the source-of-truth policy is currently **defined but not yet fully migrated**.

### Current runtime reads

| Entity | Current runtime source | Target V1.7 source | Status |
|---|---|---|---|
| Questions | `modules/questions/question-bank.json` | `content/questions/` | migrate |
| Knowledge graph | `modules/questions/taxonomy/knowledge-graph.json` | `content/knowledge/` | migrate |
| Lesson manifest | `modules/lessons/manifest.json` | `content/curriculum/` / `content/lessons/` | migrate |
| Topic index | `modules/questions/bank/questions-by-topic.json` | derived index | regenerate |
| Lessons | `modules/lessons/day-01..36.json` | `content/lessons/` | migrate |
| Experiments | `content/experiments/*.json` | `content/experiments/` | canonical |
| Knowledge detail | `content/knowledge/*.json` | `content/knowledge/` | canonical |

## Important finding

`app/content-service.js` is already the application-facing boundary, but it delegates to `engine/content-loader.js`, whose endpoints still point at `modules/` for the core lesson/question/graph data. This means V1.7 has a clean seam for migration without requiring every view/controller to change at once.

## Migration rule

1. Do not delete the current `modules/` records yet.
2. Copy/migrate one content family at a time into `content/` using stable IDs.
3. Validate the new records against their schema.
4. Switch `ContentLoader` to the canonical source.
5. Run tests and browser smoke checks.
6. Remove the legacy copy only after repository-wide references to it reach zero.

## Phase 3.1 conclusion

The earlier assumption that `modules/` might already be unused was incorrect. It is still the active runtime source for lessons, questions, knowledge graph, manifest, and topic index. The next migration must therefore be an actual data migration, not just a directory cleanup.
