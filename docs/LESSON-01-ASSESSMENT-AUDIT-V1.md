# Lesson 01 Assessment Deep Audit V1

## Scope
20 unseen mastery items + 4 transfer items for `lesson-01-material-changes-properties`.

## Audit result
**CONDITIONALLY PASS — not yet READY for 95% mastery production.**

### Strengths
- All five approved knowledge nodes are represented.
- Core misconception classes are represented.
- No copied Wuhan examination wording was identified in the authored item set.
- The central evidence-first reasoning model is consistently reinforced.
- Transfer items require explanation rather than simple answer recall.

### Findings requiring revision
1. The 20-item mastery set is heavily multiple-choice. It can measure recognition and structured judgment well, but it under-samples student-generated explanation. At least several mastery items should require short justification.
2. UM09 and UM18 use “new solid / precipitate” as evidence. The wording must avoid teaching students that any visible solid automatically proves a chemical change; the item should explicitly distinguish evidence from proof.
3. UM12 (apple color change) is appropriately cautious, but the answer should avoid implying that further evidence must always be obtainable in the classroom; it is a reasoning task, not a requirement to perform an unsafe or impractical test.
4. TR02 combines odor and color. Because odor is not an appropriate classroom test cue, the final learner-facing version should emphasize observation/recording rather than smelling an unknown material.
5. The 95% threshold is mathematically 19/20, but one missed item can materially affect the decision. Production should report the raw score, confidence/coverage metadata, and whether any critical misconception remains. A score of 19/20 with a critical misconception must not automatically be labelled mastered.
6. The transfer set is too small to independently establish a stable 95% estimate. It should be treated as a transfer gate, not as a second statistical mastery sample.

## Decision
Keep the blueprint and item architecture. Revise flagged items and add a small number of constructed-response mastery items before the final `READY` audit.

## Safety / age appropriateness
No dangerous experiment instructions are required. Unknown substances must not be smelled or directly tested by students; the course should use safe, teacher-controlled examples where experimental verification is discussed.

## Next action
Revise UM09, UM12 and TR02; convert/add several unseen items to short-answer justification format; then run final science + curriculum + age + ambiguity + diagnostic audits.
