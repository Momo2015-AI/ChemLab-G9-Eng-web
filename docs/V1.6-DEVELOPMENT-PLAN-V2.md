## 二、开发阶段规划

### Phase 1：数据层填充（预计 10-12 天）

**目标：让数据层达到可测试的最小可用状态**

#### 1.1 知识图谱补全（modules/questions/taxonomy/knowledge-graph.json）

九年级化学下册 8 章完整知识点：

```
单元一 酸和碱
  ├── acid-introduction（酸的认识）
  ├── acid-property（酸的性质）
  ├── base-introduction（碱的认识）
  ├── base-property（碱的性质）
  ├── ph-scale（pH 与酸碱度）
  ├── acid-base-reaction（酸碱中和）
  └── neutralization-application（中和反应应用）

单元二 盐 化肥
  ├── salt-introduction（盐的认识）
  ├── salt-property（盐的性质）
  ├── fertilizer-introduction（化肥种类）
  ├── fertilizer-nitrogen（氮肥）
  ├── fertilizer-phosphate（磷肥）
  ├── fertilizer-potassium（钾肥）
  └── compound-fertilizer（复合肥）

单元三 金属和金属矿物
  ├── metal-introduction（金属共同性质）
  ├── metal-reactivity（金属活动性顺序）
  ├── metal-acid（金属与酸反应）
  ├── metal-salt（金属与盐溶液）
  ├── iron-oxidation（铁的锈蚀）
  ├── iron-protection（金属防护）
  └── metal-extraction（金属冶炼）

单元四 化学方程式
  ├── mass-conservation（质量守恒定律）
  ├── equation-writing（方程式书写）
  ├── equation-balancing（方程式配平）
  ├── equation-calculation（有关计算）
  └── equation-comprehensive（综合应用）

单元五 化学与生活
  ├── nutrition-introduction（营养素）
  ├── nutrition-protein（蛋白质）
  ├── nutrition-carbs（糖类/油脂）
  ├── nutrition-vitamin（维生素）
  ├── material-organic（有机合成材料）
  └── material-synthetic（合成材料）

单元六 综合提升
  ├── exam-review-1（基础概念回顾）
  ├── exam-review-2（实验专题）
  ├── exam-review-3（计算专题）
  └── exam-final（综合诊断）
```

每个节点需包含：
```json
{
  "id": "acid-property",
  "name": "酸的性质",
  "chapter": "单元一 酸和碱",
  "domain": "substance",
  "relations": {
    "prerequisite": ["acid-introduction"],
    "related": ["base-property", "ph-scale"],
    "experiment": ["exp-acid-copper-oxide"],
    "question": ["q-acid-001", "q-acid-002"],
    "commonMistake": ["concept-error"]
  },
  "bloomLevels": ["remember", "understand", "apply"]
}
```

#### 1.2 题目库填充（modules/questions/question-bank.json）

每知识点至少 5 题（基础/提升/挑战三级）：
- 选择题（4 选 1，含 explanation）
- 填空题（含标准答案）
- 实验题（含现象/结论/方程式）

格式：
```json
{
  "id": "q-acid-001",
  "type": "choice",
  "knowledge": ["acid-property"],
  "difficulty": "easy",
  "bloomLevel": "understand",
  "prompt": "下列物质能使紫色石蕊试液变红的是",
  "options": ["A. 水", "B. 稀盐酸", "C. 氢氧化钠溶液", "D. 氯化钠溶液"],
  "answer": "B",
  "explanation": "稀盐酸呈酸性，能使紫色石蕊试液变红...",
  "commonMistake": "concept-error",
  "status": "ready"
}
```

#### 1.3 课程内容填充（modules/lessons/day01.json ~ day36.json）

每天课程结构：
```json
{
  "id": "day01",
  "title": "常见的酸",
  "module": "module-acid-base",
  "chapter": "单元一",
  "duration": "45 分钟",
  "knowledgePoints": ["acid-introduction", "acid-property"],
  "experiments": ["exp-acid-copper-oxide"],
  "questions": ["q-acid-001", "q-acid-002", "q-acid-003"],
  "sections": [
    {
      "title": "认识常见的酸",
      "body": "浓盐酸、浓硫酸的物理性质与用途..."
    }
  ],
  "summary": "本节核心：酸的通性与鉴别方法",
  "preview": "下节：碱的性质"
}
```

#### 1.4 实验数据补全（content/experiments/）

每单元至少 3-4 个实验，30+ 总量：
- 每个实验包含：目标、仪器、步骤、现象、方程式、安全事项
- 实验 ID 与知识点 `relations.experiment` 字段对应

### Phase 3：UI 页面实现（预计 7-10 天）

**目标：可完整使用的基础学习界面**

#### 3.1 首页（index.html 重写）

- 课程导航网格（8 单元 × 若干天）
- 学习进度条（localStorage 读取）
- 连续学习天数
- 待复习提示

#### 3.2 课程学习页

- 课程内容渲染（sections → DOM）
- 知识点侧边栏
- 实验入口卡片
- 完成标记

#### 3.3 实验交互页

基于现有 `lab/experiment-player.js` 扩展：
- 步骤可视化（当前步骤高亮）
- 仪器选择交互（拖拽或点击）
- 步骤验证（判断操作是否正确）
- 实验报告生成

#### 3.4 题目测验页

- 题目渲染（choice/fill/lab）
- 作答交互
- 即时反馈（正确/错误 + explanation）
- 提交评分

#### 3.5 仪表盘页（dashboard/）

- 学习进度统计
- 知识点掌握度热力图
- 实验完成历史
- 错题分布

---

### Phase 4：核心交互功能（预计 5-7 天）

#### 4.1 完整 quiz 引擎

- 题目随机/顺序模式
- 答案解析展开
- 错题自动收集
- 复习间隔算法（SM-2 简化版）

#### 4.2 错题诊断

基于 `core/diagnosis/`：
- 错误类型标签（concept-error / calculation-error / experiment-error）
- 薄弱知识点聚合
- 推荐针对性复习路径

#### 4.3 学习记录完善

- 每道题的作答时间、对错
- 每次实验的完成状态、错误记录
- 每日学习时长统计
