# V1.7 Phase 1.6 — Quiz & Result View Migration

## Completed

- Added `views/quiz-view.js`.
- Separated quiz rendering from quiz session state.
- Separated result rendering from scoring logic.
- Views receive question/session data and callbacks only.

## Boundary

```text
ContentService → AssessmentController → Assessment Engine
                                      ↓
                                  Quiz View
                                      ↓
                                     DOM
```

The view does not decide whether an answer is correct. It only reports the selected option through `onAnswer`.

## Educational requirement

The result screen should not become a simple score display. The next content iteration should expose:

- what the student understood
- which concept is uncertain
- why the selected answer was incorrect
- what evidence/model should be revisited
- one short retrieval task
- one transfer task

A score is a measurement, not the learning intervention itself.

## Migration status

Legacy rendering remains in `engine/app.js` until its callers are migrated and browser smoke tests confirm equivalent behavior.
