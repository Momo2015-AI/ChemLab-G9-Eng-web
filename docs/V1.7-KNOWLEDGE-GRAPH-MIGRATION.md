# V1.7 Knowledge Graph Migration

## Goal

Convert the legacy node-embedded relation model into the V1.7 canonical graph model without changing knowledge IDs or losing relations.

## Legacy

```text
node
└── relations
    ├── prerequisite
    ├── related
    ├── experiment
    ├── question
    └── commonMistake
```

## Canonical V1.7

```text
nodes[]
relations[]
```

Each relation is explicit:

```json
{
  "source": "concept-a",
  "target": "concept-b",
  "type": "prerequisite"
}
```

## Migration guarantees

- Stable node IDs are preserved.
- Existing explicit `relations[]` are preserved.
- Embedded legacy relations are converted to explicit relations.
- Duplicate relations are removed by `(source, type, target)` identity.
- Node records no longer contain embedded relation arrays in the canonical output.
- The migration is reproducible through `scripts/migrate-knowledge-graph.mjs`.

## Safe rollout

1. Run the migration against the legacy graph.
2. Validate the generated graph against the V1.7 schema.
3. Compare node IDs and relation counts.
4. Switch `ContentLoader` to the canonical graph.
5. Run unit and browser smoke tests.
6. Remove legacy graph data only after repository-wide references reach zero.

The legacy graph must remain untouched until all validation steps pass.
