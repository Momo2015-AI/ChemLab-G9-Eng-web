# ChemLab-G9 下册 · 课程地图与教材分析

依据 `chemlab-curriculum-development` skill 第 5、6 节流程产出。本文件是下册全部内容开发的第一事实源：任何 Day 内容都从本地图派生，不直接从教材章节批量生成。

## 1. 教材定位

人教版九年级化学下册，对应中考第三轮（金属/溶液/酸碱盐/盐化肥）主干内容，是整个初中化学难度与计算最集中的部分。上册建立"物质→变化→化学用语"基础，下册在此基础上进入"规律性认识"：金属活动性、溶解性与溶质质量分数、酸碱盐通性与复分解规律。

能力梯度：知识记忆 → 现象解释 → 规律应用 → 定量计算 → 实验设计与证据推理。

## 4. 单元一详细教材分析：金属和金属材料（Day01-06）

### 4.1 教材章节结构

第八单元金属和金属材料，三课题：
- 课题1 金属材料：金属物理性质、合金
- 课题2 金属的化学性质：金属与氧气、金属与酸、金属与盐溶液、金属活动性顺序
- 课题3 金属资源的利用和保护：金属存在形式、炼铁、锈蚀与防锈、资源保护

### 4.3 化学用语（本单元必须掌握的书写）

Fe、Mg、Al、Zn、Cu、Au、Ag、Hg、Fe₂O₃、Fe₃O₄、Al₂O₃、CuSO₄、FeSO₄、FeCl₂、HCl、H₂SO₄、CO、CO₂。

重点方程式：
- 2Mg + O₂ →(点燃) 2MgO
- 4Al + 3O₂ → 2Al₂O₃（铝表面致密氧化膜）
- 3Fe + 2O₂ →(点燃) Fe₃O₄
- 2Cu + O₂ →(加热) 2CuO
- Fe + 2HCl → FeCl₂ + H₂↑
- Zn + H₂SO₄ → ZnSO₄ + H₂↑
- Fe + CuSO₄ → FeSO₄ + Cu
- Cu + 2AgNO₃ → Cu(NO₃)₂ + 2Ag
- Fe₂O₃ + 3CO →(高温) 2Fe + 3CO₂

### 4.5 中考考点

1. 金属活动性顺序的应用：判断反应能否发生、比较金属活泼性强弱、设计实验验证顺序。
2. 置换反应的识别与方程式书写（铁与酸/盐反应生成 +2 价铁，写 FeCl₂/FeSO₄ 而非 FeCl₃）。
3. 合金特性与生铁/钢含碳量区分。
4. 含杂质化学方程式计算（与 Day33-34 衔接）。
5. 铁锈蚀条件探究（控制变量）与防锈方法。
6. 高炉炼铁的原理、原料作用、尾气处理（CO 毒性）。

### 4.6 易错点/错误分类（对应 mistakes.js）

| 错误类型 | 具体表现 | 对应知识点 |
|---------|---------|-----------|
| M-CHEMICAL-FORMULA | 铁与酸/盐反应误写 FeCl₃、Fe₂(SO₄)₃ | V2-K105, V2-K106 |
| M-CONCEPT-CONFUSION | 混淆"合金是混合物"与"合金不是纯金属"，或误认为合金"更贵所以更好" | V2-K102 |
| M-PATTERN-OVERAPPLY | 认为所有金属都能与酸反应放氢气 | V2-K105, V2-K107 |
| M-CONDITION-OMISSION | 认为铁生锈只需水或只需氧气，忽视"共同作用" | V2-K111 |
| M-CONDITION-OMISSION | 高炉炼铁忽视尾气 CO 处理 | V2-K110 |
| M-PHENOMENON-JUDGE | 只凭"气泡"判断金属活泼性强弱，不看同一条件下比较 | V2-K105 |
| M-OBSERVATION-COMPARE | 比较金属与酸反应快慢时变量不唯一 | V2-K105 |

### 4.7 题型地图

- 选择题：金属活动性顺序判断、合金说法、防锈方法、化学式判断。
- 填空题/方程式：金属与酸/盐反应方程式书写、配平。
- 实验探究题：铁钉锈蚀条件（控制变量）、金属活动性验证方案设计（三金属验证顺序）。
- 计算题：含杂质炼铁计算、金属与酸反应生成氢气计算。
- 推断题：以金属单质及其盐溶液的颜色与反应关系为线索。
