# V1.9 Question Audit — Batch 02

## Scope

This batch audits the 320-item `modules/questions/question-bank.json` against the V1.9 five-layer gate:

1. source/provenance
2. scientific correctness
3. Grade-9 age suitability
4. item quality
5. knowledge relationships

## Release decision

The question bank must **not** be treated as 320 release-ready questions. Several entries are template placeholders or contain material scientific/item-quality defects.

## P0 — block from publication

### Placeholder families

The following 12 families contain five non-content template questions each. They must remain blocked until replaced by real curriculum-aligned questions:

- `q-aci-001..005`
- `q-sal-001..005`
- `q-fer-001..005`
- `q-com-001..005`
- `q-met-001..005`

These are not acceptable source material for students because they contain placeholder strings such as “选项A”, “实验①”, “理解一”, “结论一”, and “配平正确的化学方程式”.

### Confirmed hard defects

- `q-stoich-001`: schema uses `ans` instead of the canonical `answer` field.
- `q-final-004`: prompt asks for an ignition-based identification method, while the explanation describes the glowing-splint test for oxygen; prompt/explanation mismatch.
- `q-final-c-004`: explanation is unfinished and internally contradictory; it does not establish the requested mass fraction.
- `q-final-c-005`: 4.4 g CO2 requires 10.6 g Na2CO3, which is greater than the stated 10 g total mixture. Data are impossible.
- `q-salt-008`: prompt asks about Na2CO3, while the explanation and option D describe NaHCO3 as baking powder. Content mismatch.
- `q-salt-010`: prompt reverses the impurity-removal direction; the answer corresponds to removing Na2CO3 from NaOH, but the wording says the opposite.
- `q-metal-extraction-005`: arithmetic is inconsistent. 560/0.97 is approximately 577.3 t, not 567 t.

## P1 — review before release

- `q-acid-001`: distinguish the substance HCl from hydrochloric acid solution in the wording.
- `q-organic-003`: “有机物都易燃烧” is too absolute; revise to a scientifically defensible Grade-9 formulation.
- `q-fert-P-001`, `q-fert-P-002`: knowledge link is `fertilizer-nitrogen` although the IDs and intended topic indicate phosphate fertilizer; relink and re-audit.

## Required remediation order

1. Delete/replace the 60 placeholder questions.
2. Correct all P0 scientific/item/schema defects.
3. Rebuild knowledge links for P1 mismatches.
4. Add provenance and curriculum evidence to every replacement question.
5. Recalculate difficulty and Bloom level after rewriting.
6. Run the V1.9 integrity gate.
7. Only then promote items from `review` to `verified`/`ready`.

## Important policy

Do not inflate the final question count by keeping placeholder questions. A smaller, fully verified bank is preferable to a larger bank containing fabricated or internally inconsistent content.
