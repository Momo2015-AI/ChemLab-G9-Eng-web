# V1.7 Phase 2 — Chemistry Content Model

## Goal

Move from page-oriented content to a structured learning model that supports evidence, representations, misconceptions, retrieval, and transfer.

## Lesson learning sequence

```text
Learning objective
      ↓
Phenomenon / observation
      ↓
Question
      ↓
Particle-level model
      ↓
Chemical representation
      ↓
Evidence / experiment
      ↓
Guided practice
      ↓
Retrieval practice
      ↓
Reflection
      ↓
Transfer
```

This is a pedagogical content contract, not a requirement that every lesson use every step mechanically. Short lessons may omit stages that are not instructionally useful.

## Knowledge model

Each knowledge point should eventually carry:

- stable ID
- student-facing definition
- prerequisite knowledge
- observable phenomena
- particle/model explanation
- symbolic representation
- common misconceptions
- diagnostic questions
- retrieval prompts
- transfer contexts

## Question model

Questions must identify the knowledge points they assess. Where possible they should also identify the misconception targeted by a distractor and the evidence or representation needed for the explanation.

A score alone is insufficient for mastery decisions.

## English-learning requirement

Because this repository targets English learning, content should use:

1. precise scientific English;
2. short sentences for first exposure;
3. terminology introduced before high-density explanation;
4. visual/particle representations before requiring fluent symbolic manipulation;
5. deliberate retrieval of vocabulary in scientific context;
6. no literal translation of Chinese textbook prose when the resulting English is unnatural.

## Migration strategy

Do not rewrite the entire existing curriculum at once.

1. Define schemas.
2. Select one representative lesson.
3. Convert its content.
4. Validate questions and knowledge links.
5. Run the lesson through the new rendering pipeline.
6. Compare learning flow and accessibility.
7. Migrate the remaining lessons incrementally.

## Quality gate

A migrated lesson is not complete until its objective, knowledge points, representations, misconceptions, practice, and transfer opportunities are explicit enough for the learning engine to reason about them.
