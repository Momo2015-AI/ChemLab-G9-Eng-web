# ChemLab-G9-S2-web V1.6 Architecture & Development Plan

## Project Vision

ChemLab-G9-S2-web aims to become an intelligent chemistry learning platform for Chinese junior high school students, combining textbook learning, knowledge mapping, virtual experiments, exercises, learning analytics and AI tutoring.

Core flow:

```
Textbook Content
      ↓
Structured Knowledge
      ↓
Virtual Laboratory
      ↓
Practice & Feedback
      ↓
Learning Diagnosis
      ↓
Personalized Learning
```

---

# System Modules

## 1. Learning Center

Purpose: student learning entrance and course navigation.

Functions:
- Daily learning plan (Day01-Day40)
- Chapter navigation
- Learning progress
- Completion status
- Learning statistics

Status:
- V1.5 foundation completed
- V1.6 optimization planned

---

## 2. Knowledge Engine

Purpose: transform textbook knowledge into structured learning data.

Architecture:

```
Chapter
 ↓
Knowledge Unit
 ↓
Knowledge Point
 ↓
Experiment
 ↓
Question
 ↓
Error Type
```

Functions:
- Knowledge graph
- Knowledge relationships
- Mastery tracking
- AI diagnosis foundation

Status:
- Schema created in V1.6

---

## 3. LAB Engine (Core Feature)

Purpose: build an interactive virtual chemistry laboratory.

Architecture:

```
Experiment Data
      ↓
LAB Engine
      ↓
Experiment Page
      ↓
Interaction
      ↓
Report
```

Functions:

### Equipment Library
- Test tube
- Alcohol lamp
- Beaker
- Dropper
- Gas jar
- Iron stand

### Experiment Process
- Objective
- Equipment
- Steps
- Phenomenon
- Equation
- Safety notes

### Future Extensions
- Interactive operation
- Experiment mistakes diagnosis
- Virtual experiment report

Status:
- Data model created
- Renderer foundation created

---

## 4. Question Engine

Purpose: intelligent practice system.

Functions:
- Multiple choice
- Experiment questions
- Calculation questions
- Answer analysis
- Knowledge association

Each question contains:

```
Question
Answer
Explanation
Knowledge ID
Error Type
```

---

## 5. Mistake Diagnosis Engine

Purpose: analyze student weaknesses.

Flow:

```

 ↓
Error Analysis
 ↓
Weak Knowledge Point
 ↓
Recommended Review
```

Planned for V1.7.

---

## 6. Growth System

Purpose: improve learning motivation.

Functions:

- Badges

- Mastery level

---

## 7. AI Chemistry Tutor

Purpose: personalized chemistry assistant.

Functions:
- Explain concepts
