# V1.7 Phase 1.5 — Home & Course View Migration

## Completed

- Added `views/home-view.js`.
- Added `views/course-view.js`.
- Views receive data and callbacks; they do not own storage or data fetching.
- Existing `engine/app.js` remains untouched as the compatibility runtime during migration.

## View contract

```text
Controller / Application
        ↓
      View
        ↓
       DOM
```

Views must not:

- call `localStorage` directly
- fetch lesson data directly
- contain mastery or diagnosis rules
- contain chemistry curriculum logic

## Educational design constraint

Course views should present a learning sequence rather than a document dump:

1. learning goal
2. observable phenomenon
3. particle/model explanation
4. chemical representation
5. guided practice
6. experiment/evidence where appropriate
7. retrieval practice
8. reflection and transfer

This contract will guide the later content redesign.
