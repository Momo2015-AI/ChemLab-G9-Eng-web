# V1.7 Phase 3 Migration Status

## Current runtime boundary

`engine/content-loader.js` remains the compatibility boundary and currently loads core lessons, questions, manifest, topic index, and knowledge graph from `modules/`. Experiments and knowledge detail records already load from `content/`.

## Decision

Do not switch the loader to `content/` until canonical files have been generated and verified. Do not delete legacy `modules/` data before repository-wide consumer checks pass.

## Completed safeguards

- Canonical content policy documented.
- Active source inventory documented.
- Reproducible knowledge graph migration script added.
- Knowledge graph migration verifier added.
- Canonical knowledge graph schema added.
- Content source inventory check added.

## Next migration gates

1. Generate canonical graph from the complete legacy graph.
2. Validate node/relation preservation.
3. Migrate question bank and lesson records.
4. Validate content schemas.
5. Switch `ContentLoader` endpoints one family at a time.
6. Run tests and deployment smoke checks.
7. Remove legacy data only after zero consumer references are confirmed.
