# ChemLab-G9 Curriculum Map — 人教版九年级化学 V1.0

**Status:** C1 — Curriculum Mapping
**Authority:** 2022版义务教育化学课程标准 + 人教版九年级化学教材 + 教师教学用书 + 湖北中考政策/真题校准
**Scope:** 九年级化学全年课程；本文件是课程结构与知识关系的 canonical map，不直接替代教材。

## 1. 建设原则

1. 教材决定课程边界；教师教学用书用于教学目标、重点难点、实验和教学建议校准。
2. 课程标准决定学业要求与核心素养方向。
3. 湖北中考材料只用于考试边界、能力层级和题型校准，不反向扩大教材范围。
4. 每个课题必须建立：前置知识 → 核心概念 → 证据/实验 → 表征 → 解释 → 应用 → 检测 → 纠错。
5. 题库不作为课程的知识源；题目必须从已审核知识节点和学习目标派生。
6. 不复制教材原文，不复制真题；采用原创讲解、原创图示、原创练习。

## 2. 全年课程骨架

### 上册

| 单元 | 主题 | 核心学习任务 |
|---|---|---|
| 第一单元 | 走进化学世界 | 建立化学观察、实验安全、基本实验操作与证据意识 |
| 第二单元 | 我们周围的空气 | 认识空气组成、氧气性质与制取、化学反应中的物质变化 |
| 第三单元 | 物质构成的奥秘 | 建立分子、原子、元素、离子和化学式的微观—宏观联系 |
| 第四单元 | 自然界的水 | 水的组成、净化、爱护水资源及物质分离思想 |
| 第五单元 | 化学方程式 | 质量守恒、化学方程式、化学计算基础 |
| 第六单元 | 碳和碳的氧化物 | 碳单质、二氧化碳、一氧化碳及碳循环相关认识 |
| 第七单元 | 燃料及其利用 | 燃烧条件、灭火、化石燃料、能源与环境 |

### 下册

| 单元 | 主题 | 核心学习任务 |
|---|---|---|
| 第八单元 | 金属和金属材料 | 金属性质、金属活动性、铁制品、资源与利用 |
| 第九单元 | 溶液 | 溶液组成、溶解过程、溶解度与浓度计算、常见溶液 |
| 第十单元 | 酸和碱 | 酸碱性质、指示剂、pH、中和反应及应用 |
| 第十一单元 | 盐 化肥 | 盐的性质、复分解反应、化肥、粗盐提纯与物质转化 |
| 第十二单元 | 化学与生活 | 营养物质、化学材料、生活中的化学与安全健康意识 |

## 4. 能力主线

课程不是按“知识点清单”堆砌，而沿以下能力逐步升级：

**观察 → 实验操作 → 记录证据 → 比较分类 → 微观解释 → 化学用语 → 定量推理 → 方案设计 → 综合应用。**

## 5. 课题生产契约

每个正式课题进入 production 前必须具备：

- `lesson-id`
- 所属单元/课题
- 学习目标
- 前置知识
- 核心概念
- 关键证据或实验
- 宏观/微观/符号三重表征
- 易错点与错误诊断
- 最小掌握检测
- 拓展/迁移任务
- 与湖北考试能力要求的关联标签
- 来源引用记录

## 6. 第一批生产顺序

不直接批量生成全年正文。先制作 **Benchmark Lessons**：

1. 第一单元：物质的变化和性质
2. 第二单元：氧气
3. 第三单元：分子和原子
4. 第五单元：质量守恒定律
5. 第十单元：常见的酸和碱
6. 第十一单元：常见的盐

这 6 个 benchmark 用于验证 ChemLab 的课程表达、实验呈现、知识关联、练习设计和审计标准；通过后再扩展到全部课题。

## 7. 审计 Gate

```text
G1 来源正确性
G2 科学正确性
G3 课程标准一致性
G4 九年级适龄性
G5 教学可实施性
G6 题目与评价质量
G7 知识图谱与前后置关系一致性
```

任何一个 Gate 未通过，不进入 `READY`。
