# V1.7 Content Referential Integrity

Educational content is not valid merely because each JSON file parses. Cross-entity references must also resolve.

## Required relationship

```text
Question
   │
   └── knowledge reference ──→ Knowledge Graph Node
```

The migration pipeline must reject a question that references a knowledge ID absent from the canonical graph.

## Accepted legacy question fields

The current validator recognizes the legacy forms:

- `knowledgeId`
- `knowledgePointId`
- `knowledge`
- `knowledgeIds[]`
- `knowledgePoints[]`

These fields may later be normalized into one V1.7 assessment schema, but migration must not silently discard them.

## Why this is a release gate

Mastery, diagnosis, remediation, and learning recommendations all depend on stable links between assessment evidence and knowledge concepts. A broken reference can therefore produce apparently valid UI while corrupting the learning model.
