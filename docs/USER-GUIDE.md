# ChemLab-G9-S2 用户使用指南

## 1. 项目介绍

ChemLab-G9-S2 是面向九年级学生的化学自主学习平台。

目标：

- 按课程路径完成化学学习
- 通过练习巩固知识
- 建立系统化化学思维

## 2. 学习流程

每日学习建议：

1. 阅读课程内容
2. 理解核心知识点
3. 完成互动练习
4. 查看学习反馈
5. 记录薄弱知识

## 3. 学习建议

建议按照 Day01-Day36 顺序学习，不跳跃章节。

遇到错误：

- 回顾对应知识点
- 总结错误原因
- 再次完成练习

## 4. 推荐使用设备

支持：

- PC 浏览器
- iPad Safari
- 手机浏览器

## 5. 后续功能

未来版本将增加：

- 错题本
- 学习档案
- 实验专题
- AI化学助手
