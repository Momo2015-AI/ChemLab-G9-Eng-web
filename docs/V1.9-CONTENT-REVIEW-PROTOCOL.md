# ChemLab-G9-Eng Web — V1.9 Content Review Protocol

## 1. Review order

All new or substantially revised content follows this order:

1. Content inventory and template detection
2. Curriculum/source verification
3. Scientific review
4. Grade-9 suitability review
5. Learning-design review
6. Question/item-quality review where applicable
7. Knowledge-link integrity review
8. Misconception/remediation review
9. Automated integrity gate
10. Final publication decision

## 2. Lesson review checklist

### Curriculum
- [ ] Learning objectives map to the intended curriculum scope.
- [ ] Prerequisites are identified.
- [ ] Content depth is appropriate.

### Teaching content
- [ ] Explanation contains specific chemistry facts, relationships, or reasoning.
- [ ] No template phrases remain.
- [ ] Examples are concrete and relevant.
- [ ] Observations and conclusions are distinguished.
- [ ] Worked example includes reasoning, not only an answer.

### Student suitability
- [ ] English is accessible to grade 9.
- [ ] New terminology is introduced before being assessed.
- [ ] Cognitive load is intentional.
- [ ] Tasks do not depend on unexplained advanced knowledge.

### Learning flow
- [ ] Prior knowledge activation exists where needed.
- [ ] Guided practice exists.
- [ ] Independent practice exists.
- [ ] Retrieval/recheck exists.
- [ ] The lesson has a clear next step.

### Diagnostic integration
- [ ] Important misconceptions are identified.
- [ ] Relevant question distractors map to misconceptions.
- [ ] Remediation is defined.
- [ ] Recheck is defined.

### Evidence
- [ ] Curriculum/source evidence recorded.
- [ ] Scientific review recorded.
- [ ] Age-suitability review recorded.
- [ ] Knowledge links verified.

## 3. Question review checklist

- [ ] Unique ID
- [ ] Clear stem
- [ ] Single intended answer unless explicitly multi-select
- [ ] All options complete
- [ ] Distractors are plausible
- [ ] Answer is correct
- [ ] Explanation is consistent with stem
- [ ] Calculation independently checked
- [ ] Chemical equation independently checked
- [ ] Difficulty is intentional
- [ ] Cognitive level is intentional
- [ ] Knowledge IDs resolve
- [ ] Misconception mapping is present where diagnostic value exists

## 4. Experiment review checklist

- [ ] Objective
- [ ] Apparatus/materials
- [ ] Procedure
- [ ] Conditions
- [ ] Expected observations
- [ ] Interpretation
- [ ] Conclusion
- [ ] Safety
- [ ] Common procedural mistakes
- [ ] Common interpretation mistakes
- [ ] Misconception links
- [ ] Question links

## 5. Severity

### P0 — blocking
Examples:
- scientifically false statement
- incorrect answer
- impossible calculation
- contradictory explanation
- unsafe experimental instruction
- ambiguous answer that changes the intended result
- broken content relationship that prevents learning flow
- template presented as real teaching content

### P1 — must fix before publication
Examples:
- important terminology imprecision
- significant age-suitability issue
- missing misconception for a high-risk concept
- weak or misleading distractor
- missing evidence
- important knowledge-link gap

### P2 — improvement
Examples:
- wording polish
- minor consistency issue
- optional enrichment

## 6. Review decision

`PASS` requires no unresolved P0/P1 issues and all mandatory evidence.

`REVISE` means the content may continue development but cannot be published.

`BLOCKED` is mandatory for P0 defects.

## 7. Independence rule

For high-risk scientific content, the person or automated process that authored the content should not be the sole final reviewer. Calculations, equations, experimental claims, and safety-sensitive procedures require independent checking.

## 8. Benchmark rule

Day 01 is the benchmark. Its review record becomes the reference pattern for later lessons. A benchmark change must be documented before the same pattern is propagated to other lessons.
