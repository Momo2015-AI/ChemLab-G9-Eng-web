# V1.7 Phase 1.12 — Production Entry Point Migrated

## Completed

`index.html` now loads the new V1.7 bootstrap instead of the legacy `engine/app.js`.

## Changes

```html
<!-- Before -->
<script type="module" src="engine/app.js"></script>

<!-- After -->
<script type="module" src="app/bootstrap.js"></script>
<script type="module">
  import { bootstrap } from './app/bootstrap.js';
  bootstrap().catch(e => {
    console.error('Bootstrap failed:', e);
    document.getElementById('app-root').innerHTML = '<div class="container"><h2>启动失败</h2><p>' + (e?.message || '请刷新重试') + '</p></div>';
  });
</script>
```

## New application flow

1. `app/bootstrap.js` creates the application state
2. `app/application.js` wires together: state, router, content-service, controllers, views
3. Content is loaded asynchronously via `ContentService.load()`
4. Router starts and renders the initial route (`#home`)
5. User navigation updates hash → router re-renders

## Data flow

```
index.html
  → bootstrap.js
    → application.js
      → ContentService.load()  (fetches JSON from modules/, content/)
      → Router.start()
      → renderRoute()
        → controller.*()     (assessments, experiments, lessons)
        → view.render({ root, data })  (DOM rendering)
        → bindActions(root)  (event wiring)
```
