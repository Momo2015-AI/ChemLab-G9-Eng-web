# V1.9 Day 01 Benchmark Lesson Specification

## Purpose

Day 01 is the canonical quality benchmark for lesson production. It must be completed and reviewed before the remaining lesson set is rewritten at scale.

## Required learning arc

1. Activate prerequisite knowledge
2. Establish a meaningful context/problem
3. Introduce precise terminology
4. Explain the core chemistry concept
5. Connect evidence/observation to the concept
6. Work through a representative example
7. Expose a common misconception
8. Guide the learner through correction
9. Provide authentic practice questions
10. Check understanding
11. Route errors to remediation
12. Recheck the repaired concept
13. Summarize and retrieve

## Required content objects

- lesson metadata
- learning objectives
- prerequisite knowledge IDs
- concept/knowledge IDs
- explanatory sections
- worked example
- question IDs
- misconception IDs
- experiment IDs when applicable
- remediation IDs
- recheck question IDs
- provenance
- scientific review
- age-suitability review
- final status

## Quality test

A reviewer should be able to answer “yes” to all of the following:

- Could a grade-9 student learn the target concept from this lesson without generic filler?
- Is every chemical claim scientifically defensible at the intended curriculum level?
- Does the worked example show reasoning?
- Do practice questions actually exist and match the taught content?
- Can a wrong answer be interpreted as evidence of a specific misconception when appropriate?
- Is there a meaningful remediation route?
- Is there a recheck that tests recovery rather than repeating the same item?
- Do all IDs resolve?
- Has the lesson passed all required review gates?

## Benchmark rejection conditions

Reject the benchmark if it contains:

- generic template sections
- fake or missing question references
- unsupported scientific claims
- answer/explanation contradictions
- unexplained prerequisite jumps
- assessment content that was not taught
- diagnosis with no misconception data
- remediation with no recheck
- unresolved P0/P1 defects
