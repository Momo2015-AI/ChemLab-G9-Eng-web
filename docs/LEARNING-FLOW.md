# ChemLab-G9 课程学习流程与页面规范

> 本文合并自 COURSE-LEARNING-FLOW-V1.0（课程级流程基准）与 course-design/LESSON-PAGE-LEARNING-FLOW-V1.0（页面级规范），合并日期 2026-08-16。原两份文件已删除。

## 第一部分：课程级学习流程基准

ChemLab 不是"内容卡片展示站"，而是面向九年级学生的完整自学系统。每一课必须形成：

**理解 → 应用 → 实验/证据 → 练习 → 诊断 → 补救 → 陌生情境迁移 → 95% Mastery** 的闭环。

"95%"是课程完成标准，而不是页面上的装饰性指标。最终 Mastery 必须通过未见过的变式/陌生情境题验证。

## 2. 页面层级

### A. 学习中心首页

职责：选择学习路径，不承担完整教学。

- 上册 / 下册
- 单元
- 课程卡片
- 学习进度

### B. Lesson Overview（课程首页）

职责：让学生知道为什么学、学什么、怎么学。

固定顺序：

1. 课程标题与简介
2. 本节课要掌握什么？
3. 学习路线：学习 → 实验 → 练习 → 检查 → 掌握
4. 一步一步学入口
5. 实验、练习、诊断入口

### C. Guided Learning（核心教学）

职责：真正讲知识，不是摘要卡片。

每个步骤由：

**学习卡片 → 展开 → 知识讲解 → 示例/证据 → 思考 → 即时检查 → 解析** 组成。

卡片只是导航；正文才是教学内容。

### D. Experiment（实验探究）

职责：把抽象知识转化为可观察证据。

流程：

观察 → 记录现象 → 解释 → 得出结论 → 与概念关联。

### E. Practice（练习）

至少覆盖：

- 基础概念
- 判断/分类
- 基础应用
- 易错点
- 情境应用

### F. Diagnosis（诊断）

职责不是单纯给分，而是定位：

**错题 → 知识点 → 错误类型 → 补救内容**。

### G. Remediation（补救）

未达标学生回到对应 Guided Learning 知识步骤，重新学习并完成短检查，不应无意义重复整课。

### H. Mastery（掌握验证）

必须使用学生此前没有直接见过的变式或陌生情境。

通过标准：**得分率 ≥95%**。

未达到标准：回到诊断/补救环节。

## 3. 第一课 Golden Lesson

第一课《物质的变化和性质》作为标准课程样板。

Guided Learning 固定为 8 步：

1. 先观察：什么发生了变化？
2. 认识物理变化
3. 认识化学变化
4. 学会判断：有没有生成新物质？
5. 认识物理性质
6. 认识化学性质
7. 把四个概念放在一起
8. 用陌生情境检验理解

## 4. 内容与导航的边界

- 学习中心：导航
- Lesson Overview：课程地图
- 学习卡片：步骤导航
- Guided Learning：完整知识讲解
- 实验：证据获取
- 练习：熟练化
- 诊断：定位问题
- 补救：针对性再学习
- Mastery：最终验证

禁止把同一知识点在多个模块各自维护一套独立正文。

## 5. 数据架构原则

Canonical Lesson ID 是唯一课程身份。

生产课程内容必须通过 canonical lesson manifest → lesson JSON → Guided Learning/experiment/practice 等子资源组织。

禁止重新引入旧 day/course 平行课程体系作为生产数据源。

## 6. UI 原则

1. 页面按学习流程排列，而不是按技术模块排列。
2. 编号是视觉层级的重要锚点，步骤编号应明显。
3. 信息少的卡片采用紧凑高度。
4. 不用英文术语替代学生面对的中文教学文案。
5. 卡片不承担完整知识讲解。
6. 答案默认隐藏，提交后才显示结果与解析。
7. 不允许出现“看起来完成了”但没有真正学习内容的空入口。

## 7. 后续课程验收标准

新课程进入生产前必须回答：

- 学生从哪里进入？
- 第一屏知道要掌握什么吗？
- 是否存在清晰的学习顺序？
- 每个知识步骤是否有完整讲解？
- 是否有证据/例子支持理解？
- 是否有即时检查？
- 错误能否定位到知识点？
- 是否提供针对性补救？
- 最终是否用陌生题验证？
- 是否达到 ≥95% Mastery？

任何一项缺失，课程不得标记为 Golden/Production Ready。

## 第二部分：页面级学习流程规范

以下规范原以 Lesson 01 为首个验收样本制定，适用于全部课程页。

首个验收样本：Lesson 01《物质的变化和性质》

## 设计视角

页面不是“内容目录”，而是一个初三学生完成一节课的学习路径。
学生进入页面后应该始终知道三件事：

1. 我现在学什么？
2. 我下一步做什么？
3. 我怎样知道自己真的学会了？

## 学生实际学习顺序

### 0. 进入课程
- 看到课程名称、学习目标、预计时间和整体流程。
- 不首先看到大量题目或技术术语。

### 1. 先学懂
- “本节课要掌握什么”作为短目标区，而不是正文。
- “一步一步学”是页面主体。
- 每一步包含：核心讲解 → 例子/证据 → 即时检查 → 反馈。
- 默认展开当前推荐步骤，其余步骤可回看。

### 2. 再动手/观察
- 学完核心概念后进入实验探究。
- 实验结构：任务 → 观察 → 记录 → 证据 → 结论。
- 实验不是独立游戏，而是验证刚学知识。

### 3. 再练习
- 基础练习紧跟实验之后。
- 目的不是追求高分，而是检查是否真正理解。

### 4. 出错就诊断
- 错误必须关联到知识点和错误类型。
- 学生看到“哪里错了”和“为什么错”，而不是只看到错题数量。

### 5. 补救与再检测
- 根据薄弱知识点返回对应讲解。
- 完成少量针对性题目后再次检查。
- 已掌握知识不重复刷题。

### 6. 最终 Mastery
- 使用未直接见过的变式/陌生情境。
- Lesson 01：20题，≥19题正确即达到95%。
- Mastery 是“是否掌握”的证据，不是普通练习。

### 7. 完成本课
- 只有 Mastery 达标后解锁。
- 完成后返回学习中心，下一课成为推荐学习目标。

## 页面视觉优先级

1. 当前学习阶段
2. 当前要做的事情
3. 核心知识内容
4. 即时反馈
5. 下一步
6. 可选回看内容

不要让“知识点数量、题目数量、技术状态”等开发信息压过学生真正要学习的内容。

## 允许回看，但不允许伪造掌握

课程不采用僵硬的“上一阶段完成后才能点击下一阶段”锁链。学生可以回看知识、实验和练习；但是：

- 不能通过点击按钮直接标记完成。
- Mastery 成绩必须由 Assessment Runtime 计算。
- 未达到95%时进入补救，而不是显示“已掌握”。

## 基准课验收标准

- [x] 学习目标与课程标题一致
- [x] Guided Learning 全部可呈现
- [x] 实验资源可进入
- [x] 基础练习可进入
- [x] 诊断/补救有明确位置
- [x] Mastery 独立于基础练习
- [x] Mastery 阈值为95%
- [x] 完成本课有 Mastery 门禁
- [x] 数字答案与 A/B/C/D 答案索引统一
- [ ] 浏览器实际端到端回归测试

## 禁止的页面模式

- 只显示“本节课要掌握什么”，下面没有正文。
- 把所有内容压成知识卡片，没有深入讲解。
- 练习、实验、Mastery 随意排列，没有学习目的。
- 点击“完成”即获得课程完成状态。
- 正确答案因为不同数据格式被全部判错。
