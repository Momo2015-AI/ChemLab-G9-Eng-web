## P0 findings

### P0-01 — Experiment reference mismatch

The lesson teaching "稀盐酸除铁锈" referenced `exp-hcl-fe`, while the repository experiment object inspected for the lesson is `exp-acid-rust`. This created a broken semantic link between the lesson and its actual experiment.

**Action:** lesson reference corrected to `exp-acid-rust`; lesson knowledge links expanded to include `acid-property`.

### P0-02 — Benchmark cannot be Ready while experiment schema lacks diagnostic linkage

The benchmark standard requires experiments to expose common mistakes and misconception links. The current `exp-acid-rust.json` contains steps, one equation, safety, and question links, but no explicit `misconceptions`/`commonMistakes` fields.

**Action:** experiment enrichment is required before benchmark approval. The first update attempt was rejected by GitHub due to a stale content SHA; no unverified write is claimed. Re-fetch and update must be performed before the benchmark is promoted.

## P1 findings

### P1-01 — q-acid-001 terminology

The existing explanation says `HCl` is "氯化氢的水溶液", which is chemically imprecise. HCl denotes hydrogen chloride; hydrochloric acid is the aqueous solution. This is already recorded in the quarantine/review registry. fileciteturn127file0L2-L2

The lesson itself correctly introduces this distinction, but the question must also be corrected before publication.

### P1-02 — q-acid-004 first-aid wording

The question currently specifies a 3%–5% sodium bicarbonate solution after washing. Because this is a safety-sensitive procedural statement, it requires independent source verification and should not be accepted merely because it appears in legacy textbook-derived content. Until verified, the item remains review-only.

### P1-03 — Experiment observation vs interpretation

The current experiment records "solution becomes yellow" as an observation and gives the Fe2O3/FeCl3 equation. The benchmark should explicitly distinguish observation from interpretation and avoid presenting a simplified visual observation as a universal diagnostic signature.

### P1-04 — Experiment duration / concentration

The experiment currently lacks enough condition metadata to reproduce the intended observation consistently. Concentration, approximate amount, and stopping condition should be described as teaching conditions rather than implying an exact universal result.
