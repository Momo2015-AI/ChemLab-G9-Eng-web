## Important limitation

The diagnostic questions are currently stored in the content layer with `status: review`. They should not be treated as part of the production question bank until the question-bank integration contract is verified. This avoids silently introducing unresolved IDs into the existing runtime.

## P1 — Recheck design

A true recheck should normally be a new item with the same target misconception but a different surface form. Reusing the exact diagnostic item as both practice and recheck is acceptable only as a temporary development state and should be replaced before benchmark release.

Therefore the final benchmark should add separate recheck variants for all three misconception routes.

## P1 — q-acid-001

The legacy question still contains the HCl/hydrochloric-acid terminology defect. The new diagnostic question does not remove the need to correct or quarantine the legacy item before Day 01 is Ready.
